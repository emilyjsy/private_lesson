Layer 1 · 문장의 뼈대
🏗️
문형 (형식)
Sentence Patterns
문장의 기본 골격. 주어·동사·목적어·보어의 배열 방식. 모든 영어 문장은 5가지 형식 중 하나에 속하며, 이후 모든 문법의 출발점이 됨.
1형식 SV 2형식 SVC 3형식 SVO 4형식 SVOO 5형식 SVOC
⏱️
시제
Tense
동사의 형태를 통해 시간 정보를 나타냄. 단순·진행·완료·완료진행의 조합. 시제는 문형 속 동사(V)가 어떻게 변형되는지를 결정함.
현재/과거/미래 진행형 완료형 완료진행
↓ 동사(V)에서 파생 · 확장
Layer 2 · 동사 중심 확장
🔧
조동사
Modal Verbs
동사 앞에 붙어 가능·의무·추측 등 의미를 추가. 시제와 밀접하게 연관되며, 가정법에서 핵심 역할을 함.
can/could will/would may/might must/should had better
🔄
수동태
Passive Voice
목적어(O)를 주어 자리로 이동. 「be + p.p.」 구조. 3형식 이상 문형에서만 성립하며 시제 변화와 함께 적용됨.
be + p.p. by + 행위자 4형식 수동 5형식 수동
💭
가정법
Subjunctive
현실과 반대되는 가정을 표현. 시제를 한 단계 앞으로 당겨 사용. 조동사(would/could/might)와 항상 함께 등장.
가정법 과거 가정법 과거완료 I wish as if
↓ 동사를 명사·형용사·부사로 변환
Layer 3 · 준동사 (동사의 변신)
∞
부정사
Infinitive (to-V)
「to + 동사원형」. 동사를 명사·형용사·부사로 사용. 5형식 목적격보어로도 쓰임. 의미상 주어는 「for + 목적격」.
명사적 용법 형용사적 용법 부사적 용법 원형부정사
✦
동명사
Gerund (-ing)
동사 + -ing → 명사 역할. 주어·목적어·보어 자리에 위치. 부정사와 목적어 자리를 두고 경쟁하며 의미가 달라지는 동사가 중요 포인트.
주어 역할 목적어 역할 동명사 vs 부정사 관용표현
◈
분사
Participle
-ing(현재분사)·p.p.(과거분사) → 형용사 역할. 명사 수식 또는 보어. 분사구문으로 확장 시 부사 역할도 담당.
현재분사 -ing 과거분사 p.p. 분사구문 독립분사구문
↓ 문장과 문장, 명사와 동사를 연결
Layer 4 · 연결과 수식
🔗
접속사
Conjunction
단어·구·절을 연결. 등위접속사는 대등한 요소를, 종속접속사는 주절과 종속절을 이어 복잡한 문장 구성.
등위 and/but/or 명사절 that 부사절 when/if 상관접속사
🧩
관계사
Relative
접속사 + 대명사/부사의 기능을 동시에 수행. 선행사를 수식하는 형용사절을 이끌거나(관계대명사), 장소·시간·이유를 나타냄(관계부사).
who/which/that whose/whom where/when/why what (선행사 포함)
📍
전치사
Preposition
명사 앞에 위치해 장소·시간·방향·방법 등의 의미 추가. 전치사구 전체가 형용사 또는 부사 역할을 함.
in/on/at (장소·시간) for/of/with 전치사 + 동명사 전치사 관용표현
↓ 전체 문법 위에서 작동하는 규칙
Layer 5 · 규칙과 특수 구문
⚖️
수일치
Subject-Verb Agreement
주어의 수(단·복수)에 맞춰 동사 형태를 일치시키는 규칙. 부분표현(most of / a number of 등), 부정대명사(every·each·both), 수를 착각하기 쉬운 명사가 핵심 출제 포인트.
부분표현 + of every/each → 단수 the number of a number of
📊
비교구문
Comparison
형용사·부사의 원급·비교급·최상급으로 정도를 비교. 비교 대상의 격(주격 vs 목적격)과 병렬 구조가 주요 오류 포인트.
as ~ as (원급) -er / more (비교급) -est / most (최상급) the + 비교급, the + 비교급
✨
특수구문
Special Structures
도치·강조·생략·삽입 등 어순이나 구조가 기본 문형에서 벗어난 구문. 수능에서는 주로 도치(부정어구 강조)와 it ~ that 강조구문이 출제됨.
도치 it ~ that 강조 생략 병렬 구조
